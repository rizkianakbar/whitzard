# Security

Whitzard is an MVP running on the Sepolia testnet. Its tokens have no monetary value, and the
contracts have not been professionally audited. Don't deploy them with real funds.

## Reporting a vulnerability

If you find a security issue, especially in the contracts under [`blockchain/`](blockchain/),
please report it privately through
[GitHub's private vulnerability reporting](https://github.com/rizkianakbar/whitzard/security/advisories/new)
rather than opening a public issue. Include the affected contract or service, the steps to
reproduce, and the impact you expect.
